# Scene Blocks Lite 0.3.8

- Кнопка **«Загрузить промпт JSON»** теперь автоматически принимает два формата:
  - собственный JSON одного промпта Scene Blocks Lite;
  - один `generated` G-блок из старого ExtBlocks.
- Старый ExtBlocks G-блок переносится как новый сохранённый промпт: `prompt`, `template`, число последних сообщений и включённые текстовые context-поля сохраняются.
- Существующие сохранённые промпты не удаляются и не перезаписываются.
- После импорта отдельно напоминается проверить профиль подготовки сцены и источник изображения.
- Старые кнопки совместимости/резервного импорта оставлены без изменений.
