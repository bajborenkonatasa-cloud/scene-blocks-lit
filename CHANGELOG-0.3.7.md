# Scene Blocks Lite 0.3.7

- Added one-click export of the active prompt to a portable JSON file.
- Added one-click import of a portable Scene Blocks prompt JSON.
- Imported prompts are merged as a new preset and never replace existing presets.
- Connection profile is matched by name when possible; otherwise the recipient keeps their current profile.
- Legacy ExtBlocks/full-settings import-export remains available under compatibility tools.
- Existing SillyImages, NovelAI Worker and scene persistence logic are unchanged.
