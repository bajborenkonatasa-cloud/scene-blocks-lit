# Мои сцены · Scene Blocks Lite 0.2.0

Личное расширение для SillyTavern: сохранённые промпты, картинки и HTML/CSS
в чате. Это отдельная облегчённая реализация основных задач G-блоков.

## Что изменилось в 0.2.0

- **«Как в промпте»**: одна картинка, несколько изображений, текст либо HTML/CSS.
  Изображения остаются на своих местах внутри полученного HTML.
- **«Комикс → HTML/CSS → отдельная картинка»**: прежний строгий режим.
  Проверяются ровно две картинки и непустой HTML/CSS артефакт.
- Собственный список сохранённых промптов. У каждого своё название, инструкция,
  шаблон, контекст, профиль подключения, параметры модели и формат результата.
- Можно перенести весь активный набор G-блоков из ExtBlocks и затем пользоваться
  новым списком при выключенном ExtBlocks. Одинаковые названия допустимы;
  полностью одинаковые повторные импорты не добавляют копию.
- Повтор только недостающих изображений или одной выбранной картинки.
- Сцены и настройки 0.1.0 читаются. Прежний текущий промпт сохраняется в строгом
  режиме; новые импортированные G-блоки используют режим «Как в промпте».

## Обновление уже созданного репозитория

1. Распакуйте `Scene-Blocks-Lite-0.2.0.zip` на телефоне.
2. Откройте свой существующий репозиторий на GitHub:
   [scene-blocks-lit](https://github.com/bajborenkonatasa-cloud/scene-blocks-lit).
3. Через **Add file → Upload files** загрузите из новой папки пять файлов:
   `index.js`, `manifest.json`, `style.css`, `README.md`, `LICENSE`.
   В мобильном представлении меню добавления файлов может выглядеть как **+**.
   Файлы с этими же именами должны заменить прежние в корне репозитория.
4. Нажмите **Commit changes**. Новый репозиторий создавать не требуется.
5. Если расширение уже установлено, откройте управление расширениями
   SillyTavern, проверьте обновления и обновите **«Мои сцены»**. Перезагрузите
   страницу Таверны. В заголовке настроек должна появиться версия **0.2.0**.
6. Если ещё не установлено — используйте ту же ссылку на репозиторий.

Вложенный `source-code.zip` содержит исходники и тесты для доработок.
Для обычной установки достаточно пяти перечисленных файлов.

## Переход с ExtBlocks

1. Пока оставьте старое расширение установленным и сохраните его набор через
   встроенную кнопку экспорта ExtBlocks как запасную копию.
2. В **«Моих сценах»** нажмите **«Сохранить весь набор G-блоков»**.
   Переносятся G-блоки активного набора и применимые блоки персонажа.
   Посмотрите число перенесённых и пропущенных блоков. Варианты с неподдерживаемым
   контекстом или зависимостью от другого блока пропускаются с уведомлением.
3. При необходимости выберите следующий набор в ExtBlocks, нажмите
   **«Обновить списки»** в новом расширении и повторите перенос.
4. В **«Моих сохранённых промптах»** выберите нужный вариант.
5. Для вашего `comicss` выберите формат
   **«Комикс → HTML/CSS → отдельная картинка»** и нажмите **«Сохранить»**.
   Для произвольного количества картинок и HTML используйте **«Как в промпте»**.
6. Проверьте **«Подключение для подготовки сцены»**. Это существующий профиль
   Connection Manager; при однозначном совпадении старого API-пресета он
   переносится автоматически. Новые ключи в «Мои сцены» вводить не нужно.
7. Снимите галочку **Enable ExtBlocks** в старом расширении. Его сохранённые
   настройки остаются. **SillyImages оставьте установленным и включённым** —
   для картинок используются его генератор, стили и референсы.
8. На копии чата нажмите **«Создать / продолжить»** для готового ответа.
   После успешной проверки включите **«Автоматически после нового ответа»**.

Если другие блоки ExtBlocks вам ещё нужны, можно оставить его включённым,
выключив только старые блоки генерации картинок, которые заменяет новое
расширение. Не запускайте два генератора одной сцены одновременно.

Перенос копирует строки промпта и шаблона без сокращения. Тексты G-блоков
не включаются в публикуемый код и не отправляются на GitHub.
Можно также использовать **«Импорт G-блока»** для JSON одного блока.
Экспорт «Моих сцен» содержит весь список сохранённых промптов; при обратном
импорте он объединяется с текущим списком.

## Свой новый промпт

1. Нажмите **«Новый промпт»**.
2. Введите название и вставьте творческую инструкцию.
3. Оставьте **«Как в промпте»** либо выберите строгую схему комикса.
4. При необходимости добавьте HTML-шаблон. В свободном режиме он необязателен.
5. Выберите профиль подключения и нажмите **«Сохранить»**.

Примеры задач для свободного режима: один портрет по сцене; несколько
иллюстраций в сетке; комикс без дополнительной картинки; письмо, телефон
или дневник на HTML/CSS; текстовый информационный блок.

Поддерживается до 100 сохранённых промптов. Активен один выбранный промпт.
Переключение не перерисовывает старые ответы автоматически: новый промпт
применяется к следующим сценам. Для существующего блока нажмите **«Обновить всё»**.
При переключении изменения предыдущего промпта сохраняются.

В свободном режиме предел — **8 изображений на блок** по умолчанию;
его можно изменить от 1 до 20 в дополнительных настройках конкретного промпта.
Это верхний предел, а не обязательное число картинок: HTML-блок может быть
совсем без изображений. Блоки без изображений не обращаются к SillyImages.

## Использование в чате

- **«Сцена»** в меню ответа — подготовить блок или продолжить незавершённый.
- **«Продолжить»** — повторить недостающие картинки, сохранив успешные.
- В свободном блоке выберите номер картинки и нажмите **«Повторить выбранную»**.
  **«Открыть картинку»** откроет сохранённый файл в полном размере.
- В строгом режиме есть отдельные кнопки повторения комикса и иллюстрации.
- **«Обновить всё»** заново готовит блок текущим промптом. Старый результат
  сохраняется, пока новый ответ модели не пройдёт проверку структуры.
- **«Стоп»** останавливает очередь; уже готовые части сохраняются.

Для запуска картинок ответ модели должен содержать теги вида:

```html
<img data-iig-instruction='{"prompt":"A scene description","style":"cinematic","aspect_ratio":"9:16","image_size":"4K"}' src="[IMG:GEN]">
```

Расширение добавляет инструкцию об этом формате к запросу автоматически.
Промпт и шаблон задают содержание и композицию. Один `img` — один запрос
к генератору; несколько панелей можно описать внутри одной картинки-комикса.
Неверный JSON в любом теге и превышение лимита обнаруживаются до запуска
картинок. При обрезанном ответе увеличьте лимит токенов.

## Сохранение и нагрузка

Один запрос к текстовой модели подготавливает весь блок. Изображения выполняются
последовательно; общая очередь ограничена четырьмя блоками. Список всех промптов
не копируется в каждую задачу и не отправляется модели: используется выбранный.

Результаты сохраняются в метаданных конкретного сообщения и активного свайпа.
Текст ответа и `display_text` не переписываются. Отображение восстанавливается
из метаданных при загрузке чата. Смена чата, свайпа, изменение или удаление
сообщения отменяют запись запоздавших результатов в изменённый ответ.
Повторное отображение сообщения не создаёт повторный платный запрос.

При сбое загрузки уже полученные байты до двух картинок временно хранятся
в памяти вкладки для повторного сохранения. При закрытии вкладки или смене
чата этот временный запас сбрасывается. Если не сохранился сам чат, нажмите
«Продолжить» до перезагрузки: ссылка остаётся в памяти, и повторное рисование
готовых картинок не требуется.

HTML проходит DOMPurify. CSS находится в Shadow DOM; вне экрана анимации
можно приостанавливать. Постоянного опроса DOM нет. Картинки также могут
попадать в альбом SillyImages, сохраняя отображение внутри блока.

Сложная анимация, большие изображения и сами API по-прежнему требуют времени
и ресурсов. Облегчённый интерфейс не ускоряет сервер генерации.

## Совместимость и границы

Это упрощённая замена **независимых G-блоков для картинок, текста и HTML/CSS**.
Полное совпадение со всеми функциями ExtBlocks не заявляется:

- одновременно выбран один промпт;
- автоматический запуск — после нового ответа персонажа;
- из Context Builder переносятся текст и число последних сообщений;
- зависимости от предыдущих блоков и другие источники контекста требуют
  отдельной доработки и не импортируются молча;
- S/A-блоки, произвольные скрипты, JavaScript, iframe, инъекция результата
  обратно в контекст основной ролевой модели и сложные триггеры не реализованы.

Промпты остаются редактируемыми. Стартовый пример рассчитан на неоткровенные
сцены. Расширение не отменяет ограничений выбранных провайдеров.

Контракты сверены с исходниками SillyTavern **1.18.0** и
[SillyImages](https://github.com/0xl0cal/sillyimages), commit
`752215dc1ff74ba50d23a992bc6d83f31a5eb38e`. Нужен штатный
`ConnectionManagerRequestService`. Изменение внутренних модулей SillyImages
может потребовать обновления связки. Название его папки задаётся в дополнительных
настройках; по умолчанию `sillyimages`.

Пройдены **23 теста ядра** и интеграционная проверка DOM: строгий и свободный
форматы, 0/1/3 картинки, сохранение положения изображений, повтор выбранной
картинки, сохранение промптов, импорт набора, работа после отключения ExtBlocks,
совместимость прежних настроек и защита от поздних результатов.
Ответы моделей и загрузка картинок в этих проверках имитируются. Настоящие
платные API и внешний вид в вашей установке SillyTavern ещё нужно проверить
первым ручным запуском.

## Первая установка через GitHub

1. Распакуйте установочный ZIP.
2. Войдите в GitHub и откройте https://github.com/new.
3. Создайте публичный репозиторий с удобным именем. Дополнительное создание
   README и лицензии оставьте выключенным: они уже находятся в архиве.
4. Нажмите **uploading an existing file → choose your files** и выберите
   `index.js`, `manifest.json`, `style.css`, `README.md`, `LICENSE`.
5. Сохраните через **Commit changes**. Все пять файлов должны находиться
   непосредственно в корне репозитория, без вложенной папки.
6. В SillyTavern откройте **Расширения → Установить расширение** и вставьте
   ссылку на репозиторий. Обновите страницу и откройте **«Мои сцены»**.

На Android выбирайте папку через внутреннюю память телефона в файловом окне.
Категория «Документы» может показывать не все нужные типы файлов.
Загружайте в публичный репозиторий только код из установочного архива.
Личные экспорты, ключи и чаты остаются в Таверне.

При прямой установке на сервер можно поместить всю распакованную папку в
`SillyTavern/data/<user-handle>/extensions/scene-blocks-lite/`.
Внутри неё сразу должен находиться `manifest.json`.

## Для разработчика

Установочные файлы не требуют npm. DOMPurify берётся из SillyTavern,
а генератор и референсы — из установленного SillyImages.
Код написан отдельно: исходники ExtBlocks и ST-Info-Blocks в него не включены.

Распакуйте `source-code.zip`. Команды для Node.js 22+:

```sh
npm test
npm install
npm run build
```

Сборка создаёт пять установочных файлов в `dist/scene-blocks-lite`.

Интеграционная проверка DOM:

```sh
npm install --no-save jsdom dompurify
node tests/dom.mjs
```

Необязательный `tests/browser.mjs` предназначен для Playwright и Chromium;
в этой среде визуальная проверка браузером не проводилась.

Основные модули: `core.js` — очередь и сохранение; `config.js` — настройки
и промпты; `html.js` — форматы и очистка; `adapters.js` — связь с API;
`ui.js` — интерфейс.
